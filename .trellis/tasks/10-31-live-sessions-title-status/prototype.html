状态信号

目标是窗口里选中的会话：—

Failed / Stopped 是吸收态：迟到的 TurnEnd 不会把失败改写成就绪。

标题来源（单调升级）

  • user用户改名 —— 永不被覆盖
  • native恢复会话的 topic、落盘标题、OSC
  • promptchat 的首条 prompt 截断
  • placeholder只有 agent 名 —— 斜体、次级灰

同级允许覆盖（同一来源可能有更完整的值），降级被 should_upgrade 拒绝。

信号日志

  • 还没有信号 —— 点左侧按钮，或直接在窗口里批准那次审批。

状态 → 视觉

  • running 绿点呼吸 · chat 的 TurnStart / PTY 存活
  • awaitingApproval 黄点 · 收到 RequestApproval
  • failed 红点 · Error / 退出码非 0
  • ready 空心 · 回合之间（TurnEnd）
  • stopped 淡空心 · 用户停止 / 退出码 0 / 注销

投影关系

live_sessions::Registry 一份内存快照 · list_live_sessions()
  • tab 标题与状态点 resolveTabTitle(tab, session)
  • 单元图标角标 dominantState(sessionsOfUnit(key))
  • 侧栏会话行 <SessionList sessions={…} />

不变量

  1. 01

    三处投影同源

    侧栏会话行、tab 状态点、单元角标读的是同一份快照。改一个状态，三处同时变——不需要谁记得再去同步一次。

  2. 02

    单元角标取「最需要注意」的那一个

    awaitingApproval > running > failed > ready > stopped。没有会话的单元不画点，也不画灰色占位点。

  3. 03

    标题单调升级

    placeholder → prompt → native → user。同级允许覆盖，降级被拒绝；标题不写回 tab，渲染期派生。

  4. 04

    占位符必须看起来就是占位符

    只有 agent 名时，标题用斜体 + 次级灰。标题来源（TitleSource）是内部事实、不进 UI —— 不假装知道标题，也不编一个出来。

  5. 05

    终止态不复活

    进入 failed 或 stopped 之后，任何迟到信号都返回 None：pi 实测 Error 之后仍会来一条 TurnEnd。
