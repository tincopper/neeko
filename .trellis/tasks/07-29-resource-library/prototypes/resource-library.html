资源库管理动作 · 交互说明

对齐 vb.do Library 的三类资产思维，但按 Neeko 桌面工作区收敛：

1
统一 Library 壳
Dock / Open Resource Library Action 打开面板；Tabs = Skills · Prompts · Actions。
2
Skills 不重写
继续用现有 skillStore + Marketplace；Library 只做投影与入口。
3
Prompts 可沉淀
创建 / 搜索 / Insert 到 Agent 输入；支持从下方输入框 Save as Prompt。
4
Action Palette 可发现
静态动作 + 最近 Prompt / 自定义 Action 动态项（见 ⌘K）。
Agent input Insert Prompt 写入此处
