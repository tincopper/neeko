Line-Based Text Layout（基于曲线实际路径）

每行 textLeft = 该行所有竖线 + 所有曲线在该行 Y 处的实际 X 的最大值 + gap

场景 A：线性历史（单列 — 文字紧凑）
场景 B：简单分支 Merge
场景 C：交叉曲线（曲线从 col0 出发向右弯向 col2，穿过中间行）
布局规则

1. 基于线的位置，不是点的位置：对每一行，求该行所有曲线在 rowCenterY 处的实际 X（贝塞尔采样），而非只取端点列号。

2. 公式：textLeft(row) = max(竖线X, 曲线X(row)) + TEXT_GAP

3. 曲线路径采样：三次贝塞尔在端点间单调，用二分法求 t 使 B(t).y = rowCenterY，取 B(t).x。

4. 兜底：文字层有背景色，曲线尾端若仍越界会被隐藏，不产生视觉遮挡。
