Stash 面板 v2 — 交互原型

文件列表复用 gitlog 的 diff 文件列表样式（状态图标 + 文件名 + 目录 + 增删行数）；点击文件打开 diff tab，标题为 stash@{0}: <message>；底部操作栏统一放置 Apply / Pop。

交互说明

  • 点击 stash 条目展开内容：stash@{n}: <message> 头部 + 元信息 + gitlog 风格文件列表。
  • 点击文件行打开 diff tab：标题为 stash@{0}: <message>，含返回按钮、增删统计、Single/All 切换、文件导航 1/N。
  • 底部操作栏：Apply 保留条目，Pop 应用并移除条目。
  • 未选中条目时 Apply / Pop 置灰并提示先选择。

边界与实现约束

  • diff 按文件按需加载（git stash show -p <selector> -- <file>），规避单次 IPC 2MB 上限。
  • Pop 冲突：报错 toast，列表不刷新；成功才移除条目并更新徽标。
  • Apply 成功：条目保留，toast 提示已应用。
