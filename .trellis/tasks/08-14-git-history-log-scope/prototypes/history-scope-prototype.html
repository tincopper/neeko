▸ 展示范围 = 当前选择的分支

History 只展示当前 checkout 分支的提交（git log HEAD）。分支在 Changes 面板切换，历史自动跟随。git log --all 的“所有 refs 混排”不再使用——第三方工具（Synara 等）的孤立 checkpoint ref 因此不会出现。

若 refs/synara/checkpoints 恰是分支祖先，会作为普通提交存在，但其 synara/checkpoints 标签会被过滤、不渲染。

▸ Stash 独立 tab + refs 分类

  • Stash 是 Git Control 面板第三个 tab（位于 History 右侧），点击展示 git stash list 内容，展开查看文件变更（只读，无 apply/pop/drop）
  • refs 分类：branch/remote/tag/stash 渲染；其余非 heads/remotes/tags/stash 前缀归 tool 丢弃，未来新工具自动被排除
  • 复制 hash 改用插件 writeText，失败有反馈，不再抛 NotAllowedError
