Git Log = Dock 面板 · Diff = 单例中心 Tab

打开 Git Log 不再创建中心 gitLog tab，而是像 Commit 一样打开右侧（可左右停靠）面板。 在面板里浏览 graph / 选择 commit / 点文件时，中心只维护 一个 Diff tab 并原地复用； 打开「组合查看」后，同一个 Diff tab 改为纵向滚动展示该 commit 的全部文件改动。

Git Log → Dock Panel（非 tab） Diff tab 单例复用 可选 Combined multi-file scroll Commit Graph 多泳道 双击文件仍可「钉住」为独立文件 tab（可选逃生舱）
neeko / main 点击右侧 Git Log 图标打开面板

交互契约（本原型可点）

  1. 点 Dock 的 Git Log：打开/关闭右侧面板；不在中心创建 gitLog tab。
  2. 在面板 graph 中点 commit：更新面板详情与文件列表；若 Diff tab 已打开，则刷新其 commit 上下文。
  3. 点文件（单击）：打开或复用中心唯一 Diff tab，内容切换到该文件。
  4. 勾选 组合查看：同一 Diff tab 改为「commit 全部文件纵向滚动」；再点文件会滚动定位，而不是新开 tab。
  5. 双击文件：可选逃生舱——钉一个普通文件预览 tab（不占用 Diff 单例）。
  6. 快捷键：J/K 切换 commit，j/k 切换文件，c 切换组合查看，g 开关 Git Log 面板。
