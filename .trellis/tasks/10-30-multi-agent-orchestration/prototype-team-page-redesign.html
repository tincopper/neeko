创建 = 推入整屏，带 ← 返回Conductor New workspace · 移动端 push 导航 —— 一次性动作拥有完整一屏，做完即走

打开态顶部统计条（成员 / 进行中 / 待批）Omnara dashboard · OpenHands 顶栏
全 token 化，深浅两套映射跟随应用主题（右上角切换验证）

三个视图的状态归属（实现落点）

  • 视图是**导航**（就近 state / 既有 browsingFrom 同族），不进 store —— store 里的 teamId 仍是「数据面」：null = 列表/新建，非空 = 已打开。新建态不是第三个数据态，只是列表态上的一种**编辑模态**。
  • TeamListPane 的 ResizablePanelGroup（上下分栏 + 拖拽条）整体退役；三个视图都还在 agent-team/components/ 里，只是宿主从「分栏」换成「单容器 + 条件渲染」。
  • 既有契约原样保留：行 hover 动作、refusal 折叠行、成员池 accessible name 口径、C23 的 (teamId, taskId) 寻址、脉冲刷新。

不在这版原型里

  • 已打开态只是**缩略示意**（花名册/看板的真实实现已有，本原型只换导航壳）
  • 键盘全路径、读屏走查、五个应用主题的逐个验证（原型只做深/浅两套证明 token 可切换）
  • 团队重开入口（closed 行的「查看」）的推入形态 —— 与「打开」同一条路径，实现时合并
