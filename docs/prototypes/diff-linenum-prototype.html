Diff 行号列宽度优化原型

当前问题：行号列固定预留 16px 缓冲（为 hover 评论按钮预留），导致 unified 模式数字左侧、split 模式数字右侧常年空一大块。 优化方向：缓冲从 16px 收窄到 6px，评论按钮改为「覆盖在行号上」（GitHub 风格，hover 时显示），两种模式行号统一右对齐； 数字与代码之间的间隙由代码列左侧 8px padding 提供（行号列本身不增宽）。 下方对比当前版与优化版，行号列以黄色虚线框标注实际宽度。

Unified 模式（旧行号 | 新行号 | 代码）

当前版 16px 缓冲行号列 = 1ch + 16px ≈ 23px

数字右对齐 → 左侧留白 16px（表格左边缘到数字之间空一大块）

11const a = 1;
22const b = 2;
3const old = 3;
3const fresh = 3;
44const c = 4;
55const d = 5;

hover 行号列可见「+」按钮（黄色虚线框内左侧）。选中行左侧有 3px 蓝色指示条。

优化版 6px 缓冲行号列 ≈ 13px，数字↔代码间隙 8px

数字右对齐，缓冲收窄到 6px；「+」按钮覆盖在数字上（hover 显示）；代码列左 padding 8px 提供间隙

11const a = 1;
22const b = 2;
3const old = 3;
3const fresh = 3;
44const c = 4;
55const d = 5;

hover 行号列，数字被「+」按钮覆盖（GitHub 风格），不再额外占宽。

Split 模式（旧行号 | 旧代码 | 新行号 | 新代码）

当前版 16px 缓冲行号列 = 1ch + 16px ≈ 23px

行号左对齐 → 数字右侧留白 16px（数字到代码之间空一大块）

1const a = 1;1const a = 1;
2const b = 2;2const b = 2;
3const old = 3;
3const fresh = 3;
4const c = 4;4const c = 4;
5const d = 5;5const d = 5;

hover 新行号列可见「+」按钮（黄色虚线框内左侧）。

优化版 6px 缓冲行号列 ≈ 13px，数字↔代码间隙 8px

行号改为右对齐，缓冲收窄到 6px；「+」按钮覆盖在数字上（hover 显示）；代码列左 padding 8px 提供间隙

数字右对齐紧贴行号列右边缘，与代码之间由代码列 8px 左 padding 留出间隙。
