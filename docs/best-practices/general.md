# 通用工程实践

> 跨语言、跨框架的通用工程实践，适用于 React 与 Rust。

---

## 1. 可读性

- 命名清晰、函数短小（<50 行）、单一职责。

## 2. 魔法数字

- 硬编码常量提取为具名常量 / 枚举。

## 3. DRY / KISS / YAGNI

- **DRY**：重复逻辑出现 3 次以上必须抽象为共享函数/hook/util。
- **KISS**：优先选择最简单的解决方案，不过度设计。
- **YAGNI**：当前不需要的功能不实现，不预留"将来可能用到"的抽象层。

## 4. 无死代码

- 不遗留未使用的导入、变量、分支。
